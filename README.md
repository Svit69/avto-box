# Avto-box

Статистика КХЛ: создание и обновление снимков по запросу через браузер на сервере.
Примеры: `/mirror.html?id=902140#stats` и `/mirror.html?id=902144#stats`.

Открытие ссылки вызывает POST `/api/capture?id=...`: Chromium загружает HTML,
оформление, изображения, шрифты, скрипты и ответы API. Снимок передаётся потоком,
сохраняется в IndexedDB браузера посетителя и открывается через Service Worker.
Кнопка «Обновить снимок» и перезагрузка страницы заново считывают КХЛ.
Без ID открывается 902144. Поддерживается также `/mirror.html#stats+902140`.
Отправка форм отключена для сохранённой копии.

## Локальный запуск

Требуются Node.js 22 и npm. Для локального запуска на Windows нужен Chrome.

```sh
npm ci
npm run build
npm run dev
```

Открыть http://localhost:3000. Service Worker требует localhost или HTTPS.

## Дополнительное сохранение в репозиторий

`npm run refresh -- 902140 902144` сохраняет матчи через Chrome, проверяет проект,
создаёт коммит и отправляет его в GitHub. Нужна авторизация Git.
Новый ID: `npm run refresh -- 902123`. Только сохранение: `npm run capture -- 902123`.
Эти команды необязательны: новые ID автоматически загружаются при открытии ссылки.
При ошибке захвата предыдущий снимок сохраняется; его можно открыть отдельно.

## Vercel

Импортировать репозиторий Svit69/avto-box. Preset: Other.
Build Command: `npm run build`; Output Directory: `dist`.
Настройки записаны в vercel.json. Chromium входит в серверную функцию (Node.js 22).
После подключения GitHub последующие push запускают пересборку Vercel.

## Архитектура и проверки

JavaScript ESM. Абстракция: контракт PageProvider. Наследование:
BrowserPageProvider extends PageProvider. Полиморфизм: CaptureService работает
с любым поставщиком с capturePage(). Инкапсуляция: приватные поля классов.
Каждый написанный файл — до 50 строк. package-lock.json генерируется npm.
Ресурсы хранятся в Base64; успешный захват атомарно заменяет локальный снимок.

`npm test` — проверка воспроизведения ресурсов и целостности снимка.
`npm run check` — синтаксис JS, UTF-8 и длина файлов.
`npm run test:browser` — UI; `npm run test:routing` — ID; `npm run test:live` — захват и обновление.
